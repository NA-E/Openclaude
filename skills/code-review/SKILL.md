# Code Review

## Description
Review code for bugs, security issues, performance problems, and best practices.

- **Version**: 1.0.0
- **Author**: OpenClaude

## Tools
- `code_review`: Analyze code and provide review feedback

## Prompt
You can review code. When reviewing code, check for:
1. Bugs and logic errors
2. Security vulnerabilities (OWASP Top 10)
3. Performance issues
4. Code style and best practices
5. Missing error handling
6. Test coverage gaps

Provide actionable feedback with specific line references and suggested fixes.
