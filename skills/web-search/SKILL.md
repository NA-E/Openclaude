# Web Search

## Description
Search the web for information and return summarized results.
Use this skill when you need to find current information, look up facts, or research topics.

- **Version**: 1.0.0
- **Author**: OpenClaude

## Tools
- `web_search`: Search the web for a query and return results

## Prompt
You have access to web search. When the user asks about current events, recent information, or anything that requires up-to-date knowledge, use the web_search tool to find relevant information. Summarize the results clearly and cite sources.
